# Customer Segmentation Project

## Objective

The objective of this project is to segment customers based on their demographics, annual income, spending score, and purchasing behaviour.

## Tools Used

* Microsoft Power BI
* Microsoft Excel

## Dataset

The dataset contains 100 customer records with customer ID, gender, age, annual income, spending score, purchase frequency, and customer segment.

## Key Features

* Customer demographic analysis
* Gender-wise customer comparison
* Customer segment analysis
* Average age, income, and spending score
* Income vs. spending score visualization

## Outcome

This dashboard helps visualize customer groups and understand differences in spending behaviour, supporting customer analytics and targeted marketing decisions.
